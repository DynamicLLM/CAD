# Input Checklist

Use this checklist before generating a die concept.

## Target Part

- STEP file path
- number of solids
- bounding box
- nominal thickness
- key holes/cutouts
- forming features, if any
- required tolerances

## Material

- material name
- sheet thickness
- yield strength if force estimation is needed
- shear strength if blanking force is needed
- grain direction
- surface/coating requirement

## Production

- prototype, short run, or high volume
- expected annual quantity
- press availability
- coil width or stock width limits
- acceptable scrap rate

## Die Process

- one-step die, compound die, transfer die, or progressive die
- station pitch
- strip width
- carrier design
- pilot strategy
- operation order
- punch/die clearance
- slug removal strategy

## Outputs

- target part STEP
- raw strip STEP
- strip layout STEP
- upper punches STEP
- lower die STEP
- assembly STEP
- report with assumptions and checks
